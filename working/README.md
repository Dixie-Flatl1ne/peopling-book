# working/

Everything that isn't the book itself. The master manuscript (`peopling_book.md`) lives at the repo root, with its figures in `images/`.

## Sorted by type

| Folder | What | Processed? |
|--------|------|-----------|
| `drafts/` | Chapter WIPs, experimental sections, voice notes | Yes — written for the book |
| `ch7-evidence/` | Ch7 research queries, LinkedIn methodology | Yes — folded into Ch7 |
| `reviews/` | Manuscript feedback (Pascal, Claude) | Yes — informed revisions |
| `research/` | Perry, isolation/inner-peopling, published article ref | Partially — notes for future use |
| `transcripts/` | Talk transcripts (consciousness, Jiang Xueqin) | Partially — some mined, some pending |

| `publishing-site/` | Jekyll source for the GitHub Pages site | N/A — publishing |
| `archive/` | Superseded versions | Dead — do not edit |

Kept out of this public repo by `.gitignore`, and absent from the working tree:
`analysis/`, `source-materials/`, `raw-inputs/`, `job-prompts/`, `runs/`.

## Top-level files

- `book-overview-and-workbook-answers.md` — Book structure overview + Peter's retreat workbook responses

## Conventions

- Transcript filenames are lowercase kebab-case, no spaces, dated where the date is known.
- A document is superseded when a later one says so in its own header. Superseded documents
  move to `archive/`; they are not deleted.

## What is live, and what is not

- `drafts/foreword-setting-the-scene.md` is **live**. The manuscript's table of contents
  promises an "Introduction: Setting the Scene" and the manuscript does not yet contain it.
- `drafts/chapter-map-v5-human-first.md` is the current chapter map. It supersedes
  `archive/chapter-map-v4.md`, and its spine (self, pair, group, machine, bookended by
  foreword and coda) is the one the manuscript follows.
- `drafts/01-introduction-restructured.md` and `drafts/introduction-the-wrong-question.md`
  are earlier introductions written under the old book title, "The Context Layer". Kept in
  drafts rather than archived because neither is explicitly superseded by name.
- `archive/superseded-chapters/99-coda-the-universe-trying-to-wake-up.md` is the first cut
  of the epilogue. The manuscript carries a later rewrite of it.
